# 0.2.0-beta.6.2 手机回归修复

此候选针对 beta.6.1 真机反馈。保留已认可的设置与折叠帮助、Claudian 配色和 Markdown 正文，以及 Obsidian 原生导航。

## 修复内容

- 输入区：直接使用宿主与可见视口交集的像素高度。旧的百分比高度在可变高度的宿主中会按内容塌缩；输入区因此跑到顶部。定位后的内容不参与宿主自身高度计算，避免键盘收放时反向撑高宿主；同时处理视口顶部偏移。
- 历史与连接详情：和输入区使用相同的原生底栏预留空间。键盘出现后取消重复预留，保证设置入口、连接操作仍在可见区域内。
- 圆角：输入容器、状态按钮、历史分段与列表、抽屉和详情恢复圆角；历史栏仍为窄栏。
- 附件：让真实文件输入控件位于加号的 44×44 点击区域，交由系统直接处理选择，取消隐藏文件控件的代理点击。
- 重新加载：插件替换或连接关闭时结束旧桥接代际的事件流，通过现有后台重连流程重新绑定并等待确认，再恢复命令。未绑定的新插件不会被当作可执行连接。
- 版本状态：手机、中转和 Mac 的兼容性分别保留，汇总时全部通过才可发送。Mac 在线事件不能覆盖手机版本不匹配；诊断仅包含版本和白名单状态/错误码，不包含消息正文或凭据。

## 兼容与验证

插件、Companion、Relay、安装器统一为 beta.6.2，支持从 beta.4、beta.5、beta.6、beta.6.1 配套升级。继续使用已有设备身份和当前连接模式。

构建、源码边界检查、250 项 JavaScript 测试及后台与安装器 687 项 Python 测试通过。布局已覆盖 390px 空/长会话、800→500→800 高度变化、视口顶部偏移、历史和详情底栏遮挡、附件点击区域，共 66 项浏览器几何检查；这些检查模拟 Obsidian 宿主和键盘。

桥接修复经独立定向审查与 ACK/连接替换竞态检查；三层兼容状态经独立 54 项真假组合、事件顺序与脱敏检查。变更审查以本轮开始前的源文件快照为边界，未将此前版本的全部改动算作本轮修复。

## 真机边界

iPhone 镜像移至 Mac 内建显示器后已恢复点击操作。手机插件已刷新至 beta.6.2 并停用/启用以加载新代码，实际界面确认：圆角生效、历史设置完整露出且可直达连接页、连接详情操作位于原生底栏上方、加号打开的系统附件菜单紧邻加号。当前无软键盘的输入框保持在底部，三层状态校准后显示已就绪。

镜像输入工具未能输入文字或唤出 iPhone 软键盘。用户在 iPhone 软键盘下复测后确认仍会向上顶，新截图显示消息区塌缩、输入框紧贴标题，下方仍有大块空白。因此 beta.6.2 未通过软键盘验收，继续定位真实宿主布局。键盘到附件菜单切换和消息往返也未确认通过。

Mac 配套更新和安装验证通过；插件重载后确认新实例已绑定当前会话与代际，且兼容性为 ready。安装的三个插件文件与验收包逐字一致，Obsidian 未捕获错误。
