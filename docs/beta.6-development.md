# 0.2.0-beta.6.1 验收候选

本版用于手机布局、连接引导与配套升级验收。GitHub 发布和 Obsidian 社区插件上架是独立步骤；未完成真机验收前不标记正式发布。

## 界面

- 保留 Claudian 黑灰与紫色配色、Markdown 正文，以及 Obsidian 自带导航。
- 输入框位于对话底部，随内容增高，超出后在框内滚动；Enter 换行，Ctrl/Cmd+Enter 发送。
- 右侧历史栏为容器宽度的 82%，最多 300px，包含搜索、归档/恢复及底部固定设置入口。
- 连接与帮助采用 Claudian 设置页的分组、标签和折叠帮助样式。地址来源、Tailscale/VPS 环境、操作步骤与配对说明均保留。

## 安装与兼容

- 基于远端已验证的 Claudian 2.2.6 适配版本，保留原生执行事件、Steer 收据、配对超时、Keychain 安全写入、Tailscale 直连及安装恢复修复。
- 插件、Companion、Relay、安装器使用同一 beta.6.1 兼容集；支持从 beta.4、beta.5、beta.6 配套升级并保留设备身份。
- 修复插件消费一次性连接引导文件后，所有权检查误报文件缺失的问题。只有回执绑定的配置和本代认证确认均有效时才认可消费；其他缺失、篡改或身份不一致仍会阻断。
- 安装器识别并校验配对身份日志，避免将正常完成的更新误判为未知操作；孤立、篡改或尚未完成的记录仍会阻断新操作，已撤销的配对不能通过本地回滚恢复。
- 下载提供签名完整 Kit、插件 ZIP、三个 Obsidian 插件文件及配套组件。首次安装使用完整 Kit，插件 ZIP 不能替代 Mac 后台服务。
- 本地签名通过维护者已有 macOS Keychain 完成。CI 保留验证和构建；仅配置签名指纹时执行自动签名与发布。

## 验收边界

自动化覆盖构建、协议、消息与归档、布局、签名资产、防篡改、配对、更新/恢复和卸载。安装器的真实环境检查与自动化结果须分别记录。

本次候选通过 239 项 JavaScript 测试与 685 项 Python 测试。真实设置组件的 320、390、768 像素预览已检查折叠帮助和横向溢出。

浏览器中的手机键盘与宿主导航是模拟；iPhone 镜像若没有显示真实软键盘，也不能算软键盘验收通过。待真机检查输入、横竖屏、底栏遮挡、历史搜索与归档、断网草稿和消息往返后，再扩大测试范围。

更新必须配套进行。当前运行模式不会因阅读 VPS 帮助而改变；已退役的 VPS 手机身份不能通过恢复旧备份重新启用。
