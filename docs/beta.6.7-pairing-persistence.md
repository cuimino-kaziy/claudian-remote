# 0.2.0-beta.6.7 配对记录保留

修复旧共享凭据迁移后，历史 `re_pair_required` 标记在每次插件加载时清空新配对凭据的问题。仅在迁移已完成、设备身份字段齐全且 installation / vault / audience 与本地连接配置及同步仓库一致时，承认已成功保存的新配对。首次迁移仍要求验证旧凭据撤销；撤销和身份不匹配继续阻止连接。

复用现有设备本机存储、断线重连和普通更新的 preserve 策略，没有另建账户、缓存或凭据同步机制。配对码短时有效，已交付的设备凭据没有配对码的到期限制。设置和安装手册已说明长期保留行为。

回归先复现真实配对后 `loadSettings` 清空凭据，再验证跨版本重载、断线及前后台恢复保留同一设备身份，旧 token 与范围不匹配仍被拒绝。Relay 测试覆盖一年后的短码清理及进程重启后，原设备凭据仍能认证；普通更新保留设备的既有测试通过。完整校验：286 项 JavaScript、700 项 Python 通过，独立审查无阻塞。

本版本包含 beta.6.6 的能力状态变化后自动重新握手修复，输入栏布局沿用此前的修复。

首次本机更新曾因跨 iCloud 目录重命名而中断，随后使用修正版安装器沿原操作恢复完成；原有 1 台设备保留，撤销 0 台。安装和连接校验通过后，用户于 2026-09-14 确认本版使用正常并同意准备发布。最终安装过程见 [安装恢复记录](beta.6.7-installer-recovery.md)，发行范围见 [发布说明](release-notes-0.2.0-beta.6.7.md)。本记录不代表全部设备与架构矩阵已经完成。
