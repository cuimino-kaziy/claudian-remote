# 0.2.0-beta.6.3 手机键盘诊断候选

beta.6.2 的真机复测仍出现：键盘弹出后聊天区被压缩，输入框紧贴标题，下方留有大块空白。历史搜索聚焦时也会出现抽屉裁切和动画残影。因此本候选不宣称键盘问题已解决。

本版在已有“复制诊断报告”中加入内存中的布局数值快照，保留聚焦输入框或历史搜索时的现场。快照仅记录尺寸、偏移和固定状态，不记录输入文字、会话内容、DOM 文本、凭据或文件路径，也不会自动上传。

复测顺序：打开远程页，点输入框使软键盘出现；再收起键盘，打开顶部连接详情，点击“复制诊断报告”。报告中的最后聚焦样本用于区分宿主重复压缩、视口裁切和底部空白重复预留。历史搜索可按相同步骤单独复测。

保留 beta.6.2 的连接重载修复和兼容性校验。本候选继续使用已有 Tailscale 配置与手机配对，不发布到 GitHub Release 或 Obsidian 市场，不更新 VPS。
