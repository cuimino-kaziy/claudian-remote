# beta.6.7 安装恢复

本次更新在备份 Obsidian 插件目录时，跨 iCloud File Provider 目录的 `rename` 长时间未返回。中断后，内部事务已记录开始激活，外层检查点仍停留在准备阶段；已生成的连接配置又被原计划识别为环境漂移，导致恢复受阻。

安装器改为先完成本地备份，再在插件所在目录准备并替换新文件；备份恢复失败时保留恢复状态。状态查询以事务记录限制取消操作。恢复仍使用原操作和原计划，只有严格验证 journal 归属、现有版本、installation、vault、audience、凭据引用及当前 Tailscale 地址后，才接受该操作生成的配置代次变化；其他环境漂移继续拒绝。

产品版本仍为 `0.2.0-beta.6.7`。修正版安装器放在独立签名的 recovery Kit 中，原 beta.6.7 Kit 保留不变。新版本 Kit 不能绕过原计划的版本绑定。可信校验说明单独放在开发包的“可信校验”目录。

本轮 718 项 Python 测试和 20 项发布契约检查通过，签名校验与解包通过。恢复测试覆盖中断后继续安装、旧配对保留、配置身份及地址漂移、journal 归属、配置并发变化，以及备份和恢复失败。

2026-09-14 本机实测：原操作 `resume` 返回 `installation_ready`，同计划 `verify` 返回 `verification_ready`；已安装插件三项资产与签名包逐字节一致。当前运行及 Obsidian 重载后的插件均为 beta.6.7，Claudian 为 2.2.7，Bridge 已连接、已绑定且可写，状态为 `ready`。配对记录为 `ready`、策略 `preserve`，保留原有 1 台设备，撤销 0 台。

2026-09-14，用户在安装后的反馈中确认“这版本没问题，可以准备发布”。据此记录现有 Mac / iPhone 使用环境的用户验收通过；未分别取得 Intel Mac、iPad、干净安装、双人试用等完整矩阵的验收，不作扩大声明。本轮没有修改输入栏或部署 VPS；GitHub 草稿与正式发布状态见 [发布说明](release-notes-0.2.0-beta.6.7.md)，尚未上架 Obsidian 插件市场。
